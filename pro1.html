Hyper Text Markup Language

HTML stands for HyperText Markup Language. It’s the standard markup language used to structure web pages.

  1. HTML stands for HyperText Markup Language.
  2. It is used to create and structure web pages.
  3. HTML can add text, images, links, tables, forms, etc. to a webpage.
  4. HTML works together with CSS for design and JavaScript for functionality.
